# Небо открытий

Личный сайт знаний в виде 3D-неба. Каждая тема становится созвездием: презентации-схемы, их кадры и намёки на ветки, которые ещё предстоит изучить.

Сейчас на небе одна тема: Лев Толстой.

Сайт: https://marufsaidov6.github.io/sky-of-discoveries/

## Что внутри

- `index.html` — 3D-небо. Вращение, перелёт к ноде, раскрытие намёков, световые потоки между нодами, три варианта портрета в центре.
- `tolstoy/ten-frames.ru.html` — «Толстой в десяти кадрах»: жизнь и эпоха в 12 анимированных схемах.
- `tolstoy/ten-frames.en.html` — то же на английском.
- `tolstoy/gandhi-king.ru.html` — «Толстой, Ганди, Кинг»: как одна книга дошла до Ганди и Кинга.

Без сборки и зависимостей: чистый HTML. three.js и шрифты грузятся с CDN.

## Как открыть локально

```bash
python3 -m http.server
```

Потом открыть http://localhost:8000.

## Как добавить тему

Новая тема — это папка рядом с `tolstoy/` со своими страницами и новые ноды в массиве `DATA` в `index.html`.
